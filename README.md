# 極レベル早見盤

刀剣乱舞ONLINE で、**いまの累積経験値のまま修行に出したら極が何レベルで帰ってくるか**を計算するツールです。

👉 **https://yumaenginer82-svg.github.io/kiwame-level/**

刀剣男士を選んで累積経験値を入れるだけ。刀種と極後のレア度から経験値テーブルを自動で選びます。逆引き（狙った極レベルで帰すために必要な累積経験値）も出ます。

## しくみ

修行に出すと、累積経験値から「無印Lv1〜その刀種の修行可能Lv」までの分が**刀種ごとの固定額で差し引かれ**、残りを極の経験値テーブルで読み直したものが帰還時のレベルになります。

| 刀種 | 修行可能Lv | 差し引かれる額 |
|---|---:|---:|
| 短刀 | 60 | 445,300 |
| 脇差・槍・薙刀 | 65 | 540,800 |
| 打刀 | 70 | 648,800 |
| 太刀 | 75 | 770,800 |
| 大太刀・剣 | 80 | 907,800 |

極の経験値テーブルは Lv1〜34 が全刀種共通で、Lv35〜100 で刀種ごとに分岐します（打刀は極後のレア度で2種類）。Lv99 でカンストした後の経験値も無駄にならず、そのまま極へ持ち越されます。

## 検算

- 2つの出典（Wiki／刀剣乱舞速報）で 36 箇所の数値が一致することを確認
- Wiki 記載の「特Lv99 丁度で修行に出すと極Lv◯で帰る」を 9 刀種すべて再現（短刀・脇差・打刀・槍・薙刀＝Lv35／太刀・大太刀・剣＝Lv34）
- 実プレイ報告（白山吉光・累積 20,066,441 → 極Lv52）とも一致

### 既知の制限

- 剣（レア5・白山吉光）のテーブルは有志報告をもとに埋められている途中のため、値がずれることがあります
- 七星剣・丙子椒林剣は極が未実装で、テーブル自体が不明です
- 極が未実装の刀剣男士は、同じ刀種・レア度のテーブルを使った**見込み値**として表示します

## 構成

`index.html` 1ファイルで完結する静的ページです。ビルドも依存パッケージもありません。ローカルで見るならそのままブラウザで開けます。Web フォント（Google Fonts）だけ外部から読み込みます。

```
index.html              本体（HTML・CSS・JS・経験値データすべて内包）
icon.svg                ファビコン
icon-192.png            ホーム画面用アイコン
icon-512.png
apple-touch-icon.png    iOS ホーム画面用
manifest.webmanifest    ホーム画面に追加したときの設定
```

スマホでは「ホーム画面に追加」するとアプリのように開けます。前回選んだ刀剣男士と入力値はブラウザに保存され、次に開いたときに復元されます（この端末のブラウザ内だけに保存され、外部には送信されません）。
